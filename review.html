Chapter 10마무리

종합 퀴즈와 용어집

1장부터 9장까지의 내용을 한 번에 점검합니다. 틀린 문항은 해설 끝의 장 번호를 따라 돌아가 실험을 다시 해 보세요. 아래 용어집은 검색할 수 있습니다.

종합 퀴즈 20문항

글로벌 셔터와 롤링 셔터의 차이를 가장 정확히 말한 것은?

  1. 글로벌 셔터는 모든 행을 동시에 읽는다
  2. 글로벌 셔터는 모든 픽셀의 노출 시작과 끝이 같고, 읽기는 저장 노드에서 행 단위로 한다
  3. 롤링 셔터는 기계식 셔터를 쓴다
  4. 롤링 셔터는 노출 시간이 행마다 다르다
노출 창이 같다는 것이 핵심입니다. 읽기는 두 방식 모두 행 단위입니다. (1장)

2,000행, 라인 시간 10 µs인 롤링 셔터 센서로 노출 1 ms 사진을 찍었다. 위아래 행의 노출 시작 차이는?

  1. 1 ms
  2. 10 µs
  3. 2 ms
  4. 20 ms
\(2000 \times 10\,\mu s = 20\) ms. 노출 시간과 무관합니다. (1장)

IWR 모드가 가능하려면 픽셀에 무엇이 필요한가?

  1. 포토다이오드와 독립된 저장소
  2. 더 큰 마이크로렌즈
  3. 열마다 ADC 두 개
  4. IR 차단 필터
저장소에 이전 프레임을 보관하는 동안 포토다이오드가 다음 노출을 해야 합니다. (1·3장)

시속 72 km(20 m/s) 차에서 10 m 옆의 기둥을 f = 6 mm, 픽셀 3 µm, 읽기 15 ms 롤링 셔터로 찍었다. 화면 높이 전체의 어긋남은?

  1. 약 6 px
  2. 약 20 px
  3. 약 60 px
  4. 약 600 px
\(v_{px} = 20 \times 0.006 / (10 \times 3\times10^{-6}) = 4000\) px/s, × 0.015 s = 60 px. (2장)

글로벌 셔터로 바꿔도 남는 왜곡은?

  1. 세로 막대의 기울어짐
  2. 노출 시간 동안의 모션 블러
  3. 짧은 플래시의 부분 노출 띠
  4. 프로펠러가 휘어 보이는 현상
블러는 노출 시간의 문제입니다. (2장)

4T 픽셀의 CDS가 FD 리셋 잡음을 지울 수 있는 이유는?

  1. 소스 팔로워 이득이 1보다 작아서
  2. FD가 차광되어 있어서
  3. ADC가 두 번 변환해서
  4. 같은 리셋 동작에서 나온 잡음이 리셋 레벨과 신호 레벨에 똑같이 들어 있어서
리셋 → 리셋 레벨 읽기 → 전송 → 신호 레벨 읽기 순서 덕분입니다. (3장)

전압 영역 GS 픽셀에서 상쇄되지 않고 남는 잡음은?

  1. FD 리셋 잡음
  2. 포토다이오드 리셋 잡음
  3. 저장 커패시터의 샘플링 kT/C 잡음
  4. 열 ADC의 양자화 잡음만
C1, C2에 전압을 샘플링할 때의 잡음은 서로 독립이라 차이를 내도 남습니다. (3·4장)

C1 = C2 = 50 fF, 변환 이득 100 µV/e⁻, SF 이득 0.85일 때 샘플링 잡음(전자 환산)에 가장 가까운 값은? (300 K)

  1. 약 4.8 e⁻
  2. 약 0.5 e⁻
  3. 약 48 e⁻
  4. 약 16 e⁻
\(\sqrt{2kT/C} \approx \sqrt{2 \times 4.14\times10^{-21} / 5\times10^{-14}} \approx 407\,\mu V\), ÷ (100 µV × 0.85) ≈ 4.8 e⁻. (4장)

픽셀 단위 Cu–Cu 하이브리드 본딩이 작은 GS 픽셀에 주는 가장 큰 이점은?

  1. 마이크로렌즈를 없앨 수 있다
  2. 저장 커패시터와 회로를 포토다이오드 아래 웨이퍼로 옮길 수 있다
  3. ADC 비트 수가 늘어난다
  4. 컬러 필터가 필요 없어진다
면적 문제를 수직으로 풉니다. (3장)

노출 20 µs, 읽기 25 ms, PLS −90 dB인 GS 센서에서 보관 중에도 같은 밝기로 비치는 영역의 마지막 행 오염은?

  1. 약 0.004 %
  2. 약 0.4 %
  3. 약 40 %
  4. 약 4 %
−90 dB ≈ 3.16×10⁻⁵, × (25 ms / 20 µs = 1250) ≈ 0.04 = 4 %. (4장)

GS 센서를 60 °C에서 쓰다가 88 °C로 올렸다(암전류 7 °C마다 2배). 저장소 암전류는 약 몇 배?

  1. 2배
  2. 4배
  3. 16배
  4. 28배
28 °C / 7 °C = 4 → 2⁴ = 16배. (4장)

940 nm에서 실리콘의 흡수 깊이(1/α)에 가장 가까운 값은?

  1. 1.6 µm
  2. 55 µm
  3. 0.4 µm
  4. 5 mm
α ≈ 183 cm⁻¹ → 1/α ≈ 54.6 µm. (5장)

NIR QE를 올리려 광포획 구조를 넣을 때 함께 필요한 것은?

  1. 깊은 DTI
  2. 얇은 에피층
  3. IR 차단 필터
  4. 더 긴 라인 시간
옆으로 꺾인 빛과 전하가 이웃 픽셀로 새는 것을 막아야 합니다. (5장)

야외 능동 조명 카메라에서 940 nm가 유리한 가장 큰 이유는?

  1. 실리콘 QE가 더 높다
  2. LED가 더 싸다
  3. 눈 안전 규격이 적용되지 않는다
  4. 대기 수증기 흡수로 해당 대역의 햇빛이 적다
AM1.5G 스펙트럼은 930~960 nm가 깊게 파여 있습니다. (5장)

노출 100 µs, 읽기 20 ms에서 화면 전체를 고르게 비추는 데 롤링 셔터는 글로벌 셔터보다 조명 에너지가 몇 배 필요한가?

  1. 2배
  2. 20배
  3. 약 200배
  4. 2,000배
(0.1 + 20) / 0.1 ≈ 201. (6장)

조명 켜짐/꺼짐 두 프레임 차분에서 움직임 아티팩트를 줄이는 방법은?

  1. 노출을 늘린다
  2. 두 노출 사이 간격을 줄인다
  3. 필터 대역을 넓힌다
  4. 롤링 셔터를 쓴다
짧은 간격 이중 노출(예: 2 µs)이 해법입니다. (6장)

4×4 RGB-IR 배열의 특징으로 옳은 것은?

  1. 초록 50 %를 유지해 밝기 해상도를 지키고, IR 25 %·R 12.5 %·B 12.5 %이다
  2. 모든 채널이 25 %씩이다
  3. IR 픽셀이 없다
  4. 리모자이크가 필요 없다
기존 ISP와 맞추려면 베이어로의 리모자이크가 필요합니다. (7장)

하이브리드 셔터 RGB-IR 센서(예: 소니 IMX775)의 셔터 배치로 옳은 것은?

  1. RGB 글로벌, NIR 롤링
  2. 둘 다 롤링
  3. 둘 다 글로벌
  4. RGB 롤링, NIR 글로벌
컬러는 롤링의 HDR로, NIR은 글로벌의 펄스 동기로 다룹니다. (7장)

로봇 VIO에서 롤링 셔터가 만드는 평균 자세 편향은 대략 어떤 양에 비례하는가?

  1. 노출 시간 × 조도
  2. 픽셀 피치 × 해상도
  3. 각속도 × 읽기 시간
  4. 프레임률 × 비트 수
\(\Delta\theta \sim \omega T_{\mathrm{read}}/2\). (8장)

기준선 5 cm 스테레오에서 거리 1 m 물체가 기준선 방향으로 2 m/s로 움직이고 두 카메라 시각이 1 ms 어긋났다. 깊이 오차는?

  1. 0.4 cm
  2. 4 cm
  3. 40 cm
  4. 0.04 cm
\(Z v \Delta t / B = 1 \times 2 \times 0.001 / 0.05 = 0.04\) m = 4 cm. (8장)

용어집

글로벌 셔터 (global shutter)
모든 픽셀이 같은 시간 창 동안 노출하는 전자 셔터. 노출 후 신호를 픽셀 안 저장소에 두고 행 단위로 읽는다. → 1·3장
롤링 셔터 (rolling shutter)
행마다 노출 시작과 끝이 라인 시간만큼 어긋나는 전자 셔터. → 1·2장
라인 시간 (line time)
한 행을 읽는 데 걸리는 시간. 롤링 셔터의 행 간 시간차. → 1장
읽기 시간 (readout time)
첫 행부터 마지막 행까지 읽는 시간. 행 수 × 라인 시간. → 1장
ITR / IWR
노출 후 읽기(integrate then read) / 읽는 동안 다음 노출(integrate while read, 파이프라인) 모드. → 1장
스큐 (skew)
움직이는 물체나 카메라 팬으로 영상이 기울어지는 롤링 셔터 왜곡. → 2장
젤로 (jello, wobble)
카메라 진동이 행마다 다른 위치로 기록되어 영상이 물결치는 왜곡. → 2장
플래시 밴드 (flash banding)
짧은 플래시가 일부 행의 노출 창에만 걸려 생기는 밝은 띠. → 2장
플리커 (flicker)
교류·PWM 조명의 밝기 깜박임. 롤링 셔터에서는 가로 줄무늬, 글로벌 셔터에서는 프레임 간 밝기 변동. → 2장
LFM (LED flicker mitigation)
PWM 신호등·전광판이 꺼져 보이지 않도록 하는 차량용 센서 기법. → 2장
핀드 포토다이오드 (PPD)
표면을 p+ 층으로 고정한 포토다이오드. 전하를 완전히 전송하고 암전류가 작다. → 3장
플로팅 디퓨전 (FD)
전하를 전압으로 바꾸는 작은 n+ 노드. → 3장
전송 게이트 (TX)
포토다이오드(또는 저장 다이오드)의 전하를 FD로 옮기는 트랜지스터. → 3장
소스 팔로워 (SF)
FD 전압을 열 신호선으로 내보내는 버퍼 트랜지스터. → 3장
CDS (correlated double sampling)
리셋 레벨과 신호 레벨의 차이를 읽어 공통 잡음(kTC)을 지우는 방법. → 3장
kTC 잡음 (reset noise)
커패시터를 스위치로 리셋·샘플링할 때 남는 열잡음. 전압으로 √(kT/C). → 3·4장
변환 이득 (conversion gain)
전자 하나가 FD에서 만드는 전압(µV/e⁻). q/CFD. → 3장
FWC (full well capacity)
픽셀이 포화 전까지 담을 수 있는 전자 수. → 1·4장
AB 게이트 (anti-blooming, overflow gate)
포토다이오드를 전체 리셋하고 넘치는 전하를 버리는 게이트. GS 픽셀의 노출 시작을 정한다. → 3장
저장 다이오드 · 메모리 노드 (SD, MN)
전하 영역 GS에서 노출이 끝난 전하를 보관하는 차광된 핀드 다이오드. → 3장
전하 영역 GS (charge-domain GS)
신호를 전하 그대로 저장 다이오드에 보관하는 GS 픽셀. 진짜 CDS 가능. → 3장
전압 영역 GS (voltage-domain GS)
리셋·신호 전압을 픽셀 안 커패시터에 샘플링해 보관하는 GS 픽셀. → 3장
MIM 커패시터
금속–절연막–금속 구조의 커패시터. 배선층이나 아래 웨이퍼에 만들어 VDGS 저장소로 쓴다. → 3·4장
고유전율 유전막 (high-k)
HfO₂, ZrO₂, Al₂O₃처럼 유전율이 큰 막. 같은 두께에서 커패시턴스를 키운다. → 4장
TDDB
시간 의존 절연 파괴. 얇은 유전막에 높은 전계를 오래 걸 때의 신뢰성 지표. → 4장
하이브리드 본딩 (Cu–Cu hybrid bonding)
구리 패드와 산화막을 동시에 접합해 웨이퍼를 미세 피치로 연결하는 기술. → 3장
BSI (backside illumination)
배선층 반대편(뒷면)으로 빛을 받는 픽셀 구조. → 3·5장
적층 센서 (stacked sensor)
픽셀 웨이퍼와 로직(·메모리) 웨이퍼를 겹쳐 만든 센서. → 1·3장
PLS (parasitic light sensitivity)
보관 중 저장소가 빛에 반응하는 정도를 포토다이오드와 비교한 비율. 20 log로 dB 표기. → 4장
셔터 효율 (GSE)
PLS를 반대로 나타낸 글로벌 셔터 성능 지표. → 4장
암전류 (dark current)
빛 없이 열적으로 생기는 전하. 온도 6~8 °C마다 약 2배. → 4장
DSNU · PRNU
픽셀마다 다른 암신호(DSNU)와 감도(PRNU)의 고정 패턴. → 4장
PTC (photon transfer curve)
신호 대 잡음을 로그-로그로 그린 곡선. 기울기 0·½·1 구간. → 4장
다이내믹 레인지 (DR)
FWC와 잡음 바닥의 비. 20 log로 dB. → 4장
양자효율 (QE)
들어온 광자 중 전자로 바뀌어 모이는 비율. → 5장
흡수 계수 · 흡수 깊이
빛이 실리콘에서 1/e로 줄어드는 거리가 1/α. 940 nm에서 약 55 µm. → 5장
밴드갭 (band gap)
실리콘 1.12 eV. 약 1.1 µm보다 긴 빛은 흡수하지 못한다. → 5장
광포획 (light trapping)
산란·회절·반사로 빛의 실리콘 내 경로를 늘리는 구조. → 5장
DTI (deep trench isolation)
픽셀 사이를 깊은 트렌치로 막아 빛과 전하의 누설을 줄이는 구조. → 3·5장
크로스토크 (crosstalk)
빛(광학적)이나 전하(전기적)가 이웃 픽셀로 새는 현상. → 5장
MTF
공간 주파수별 대비 전달 정도. 선명도의 지표. → 5장
NIR (근적외선)
대략 750~1,000 nm 빛. 실리콘 센서의 능동 조명에는 850·940 nm를 주로 쓴다. → 5·6장
AM1.5G
지표 태양광의 기준 스펙트럼(ASTM G173). → 5장
이중 대역 필터 (DBF)
가시광과 좁은 NIR 대역만 통과시키는 필터. RGB-IR 카메라에 쓴다. → 7장
IR 차단 필터 (IR-cut)
일반 컬러 카메라에서 약 650 nm 이상을 막는 필터. → 7장
스트로브 (strobe)
노출 창에 맞춘 짧고 강한 조명 펄스. → 6장
VCSEL
수직 공진 표면 발광 레이저. ToF·구조광 조명에 쓴다. → 6장
글린트 (glint)
조명이 각막에 만드는 밝은 반사점. 시선 추적의 기준. → 6장
밝은 동공 · 어두운 동공
조명이 광축 위면 망막 반사로 동공이 밝고, 광축 밖이면 어둡다. → 6장
단속 운동 (saccade)
시선을 옮기는 빠른 눈 운동. 수백 °/s. → 6장
능동 스테레오 (active stereo)
NIR 패턴을 비춘 두 카메라의 시차로 깊이를 재는 방식. → 6·8장
구조광 (structured light)
알려진 패턴의 변형으로 깊이를 재는 방식. → 6장
iToF (indirect time of flight)
변조된 빛의 위상 지연으로 거리를 재는 방식. → 6·8장
CFA · 베이어 (color filter array)
픽셀마다 다른 색 필터를 올린 배열. 베이어는 RGGB 2×2. → 7장
RGB-IR
컬러 필터 일부를 IR 픽셀로 바꿔 컬러와 NIR을 함께 찍는 센서. → 7장
리모자이크 (remosaic)
RGB-IR 배열을 기존 ISP가 받는 베이어 배열로 다시 만드는 처리. → 7장
IR 차감 (IR subtraction)
